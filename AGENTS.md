# Trabajo en este repositorio

- No compilar, exportar instaladores, ejecutar flujos de compilación ni crear tags o releases por cada cambio. El usuario indicará expresamente cuándo hacerlo.
- Los cambios de código pueden subirse a la rama de pruebas sin iniciar compilaciones ni publicaciones. Revisar los disparadores de GitHub Actions antes de subirlos.
- Si una comprobación necesita compilar, dejarla pendiente hasta la indicación del usuario y comunicarlo con claridad.
