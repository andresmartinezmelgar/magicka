# Arcana Arena 0.29.37 — prueba de equipo mítico

Prototipo de indumentaria mítica por pieza para los cinco magos. Corona, peto, botas, remate del báculo y dos anillos comparten un atlas con cuatro vistas por pieza y anclajes para las 80 poses. Cada posición se activa por separado al equipar una pieza mítica; las calidades inferiores conservan el aspecto base.

El **Laboratorio de equipo** se abre desde **Inicio → IA / Defensa**. Permite comparar el mago base con el equipado, cambiar cada calidad, elegir mago, orientación y equipo azul/rojo, y probar reposo, marcha, lanzamiento, congelación, daño, muerte y reaparición. La pestaña Inventario muestra el mismo equipo con el renderizador del inventario. Atrás/Escape devuelve al menú. Los cambios no modifican la cuenta.

En Supervivencia, los objetos que se hayan equipado quedan protegidos de la venta automática aunque se sustituyan. Se conserva la protección al guardar y reconectar. La venta manual sigue disponible para piezas que no estén equipadas ni sean favoritas.

Esta versión se publica como **preliminar**, separada de la estable. El tag se genera después de superar la compilación, las regresiones y las comprobaciones de Godot, y exportar los paquetes firmados: `preview-v0.29.37-rN`.
