# Arcana Arena v0.16.3

- Comprobación de nuevas versiones en GitHub Releases al abrir el juego.
- Acceso directo a la descarga oficial de Android y Windows, con opción de continuar sin actualizar.
- Rechazo de conexiones PvP cuando la versión del cliente y del servidor no coincide.
- Mejoras en la interfaz del perfil, inventario y acceso por IP.
- Preparación de firma Android persistente para actualizaciones sin desinstalar.

**Nota:** para actualizar sin perder datos, instala una APK firmada con la misma clave que la versión anterior. La primera migración desde APK de depuración puede requerir reinstalación.
