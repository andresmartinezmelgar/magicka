# Círculos mágicos de puntos de control

Seis sprites transparentes de 512 × 512 extraídos de las dos láminas aportadas por el usuario.

| Mapas | Punto A | Punto B | Punto C |
| --- | --- | --- | --- |
| Clásico y Ascensión | Fuego | Hielo | Naturaleza |
| Ciudadela y Reliquias | Arcano | Solar | Cristal |

Los colores originales de cada sprite se conservan. Un anillo exterior independiente muestra el progreso azul o rojo firmado por el servidor. Durante una disputa pulsa su brillo y conserva el porcentaje. El centro y el fondo del sprite son transparentes; no se añade un disco ni un borde oscuro.

Godot importa los PNG como recursos de ambos paquetes mediante `export_filter="all_resources"`.
